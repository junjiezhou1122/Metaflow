# Wayfinder Maps

[[wayfinder/metaflow-v1-architecture/map|Metaflow v1 Architecture Map]]:
Find the canonical domain, capability, package, dependency, and interface
decisions required before the v1 framework is implemented.

[[wayfinder/metaflow-view-core/map|Metaflow View Core and Transformation Runtime]]:
The focused implementation map for immutable Views, extensible
Transformations, Capture, execution, feedback, failures, policy, shared
surfaces, verification, and v0 migration. Canonical GitHub map:
https://github.com/junjiezhou1122/Metaflow/issues/26

[[wayfinder/metaflow-agent-runtime/map|Metaflow Agent Runtime and Operator Adapters]]:
The focused decision map for warm agent sessions, ACP/Pi/Codex/workflow
adapters, ViewGraph tool access, permission gates, traces, Failure Views, and
the first Ambient-to-AgentRuntime slice.

[[wayfinder/metaflow-ambient/map|Metaflow Ambient Runtime]]:
The focused implementation map for editable Automation Views, deterministic
Triggers, exact current-context resolution, Agent Adapter handoff, lightweight
Delivery, Feedback Views, and observable Browser, macOS voice, and scheduled
summary slices. Canonical GitHub map:
https://github.com/junjiezhou1122/Metaflow/issues/45

[[wayfinder/metaflow-reactive-view-pipeline/map|Metaflow Reactive View Pipeline]]:
The focused implementation map for AI-authorable Connectors, searchable
lossless Raw Views, post-commit View events, generic Automation matching,
durable III Workers, recursive View transformations, and bounded cascade
safety. Canonical GitHub map:
https://github.com/junjiezhou1122/Metaflow/issues/55
