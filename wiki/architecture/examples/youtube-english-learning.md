# YouTube to Personal English Learning

> Status: discussion fixture, not a committed schema.

## What happened

At 10:03 the user opens an English YouTube video about why LLM agents fail.
The browser can provide the URL, title, page metadata, and playback state. The
user watches for twelve minutes, rewinds one sentence twice, and saves the
page. Existing Views say the user is interested in agent architecture, has
approximately B2 English ability, and has already mastered some related
expressions. Metaflow has not downloaded the video or transcript merely
because the page was visited.

## Desired result

Without a manual import workflow, the English Learning Application can later
show a personal learning material containing:

- why this source is relevant to this learner;
- selected excerpts rather than the full transcript;
- useful expressions and their meaning in context;
- difficulty relative to the learner profile;
- links to the exact transcript spans and source page;
- later practice and feedback connections.

## Candidate information flow

Names are deliberately provisional until the scenario establishes their
meaning:

```text
YouTube reference Raw View
+ viewing interaction Raw Views
    -> retained encounter View

Application demand
+ YouTube reference Raw View
    -> fetch metadata/transcript if available and authorized
    -> use the external result ephemerally or create another View according to
       the task's schema and policy
    -> optional content-oriented Derived View

content-oriented Derived View
+ personal-interest View
+ learner-profile View
+ mastered-material View
    -> personal English-learning-material View
```

## Questions this fixture must resolve

- Which source facts are separate Raw Views rather than fields in one capture?
- Which capture tier is justified: reference, metadata, snapshot, transcript,
  or retained media?
- What semantic objects and typed relations must the content View expose?
- What belongs in the learning-material View rather than the Application UI?
- Which transformations are generic Algebra and which are registered semantic
  Operators?
- What schema naming rule remains clear when the same transcript is
  source-provided or generated by Metaflow?
- Which output facts require AI judgment, and how are those judgments traced
  and later revised?
